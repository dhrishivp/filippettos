# Filippetto's Italian Delicatessen

Website for Filippetto's, the Italian deli, café and gelateria at 14 Chenies Parade, Little Chalfont.

A static site with no build step: open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify, etc.).

- `index.html` contains the page content, opening hours, address and links
- `styles.css` contains the styling
- `script.js` shows the "Open now / Closed now" status, using UK time
- `images/` contains the photos

If the opening hours change, update both the table in `index.html` and `HOURS` in `script.js`.
